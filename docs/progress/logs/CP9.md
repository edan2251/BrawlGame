## 1. 계획

1. 남은 디버그 단축키: F2 맵 순환, F9 입력 기록 시작·중지, F10 마지막 기록 재생, `~` 도움말(빌드에서는 처음 실행 시 열림). 튜닝 프리셋 전환 키 F11(기본 ↔ 더 빠르게).
2. 모드별 튜닝 프리셋 2개: `CombatTuning`(기본)과 `CombatTuningFast`(모드 A·B 각각 더 빠른 값).
3. 빌드 메뉴 `Knockbox/Build/Windows Development`로 `Builds/`에 개발 빌드, 실행 파일을 30초 실행해 `Player.log` 확인.
4. `docs/PLAYTEST.md`: 실행 방법, 조작표, 비교 순서, 03 7절 질문지, F9 기록 방법.
5. 전체 테스트, 사용자 보고(CP0~CP9, 측정값 비교, 관찰과 추천), Q-004 질문 후 멈춤.
