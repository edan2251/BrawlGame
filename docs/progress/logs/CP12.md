## 1. 계획

1. 경기장 크기를 맵마다(`ArenaDef.Columns/Rows`): v1 32 × 18은 테스트 고정 자료로, v2는 36 × 20. 파서는 격자에서 크기를 읽고 좌우 대칭을 검증한다. 카메라·HUD·배경은 맵 크기에 맞춘다.
2. 맵 형식 v2: 문자 격자 `<이름>.txt` + 짝 파일 `<이름>.json`(테마, 광원 위치, 순환 포함 여부, 구조물 목록 자리). 연출의 테마는 짝 파일에서.
3. 새 맵 6개(테마당 2개): 대칭, 화면 가득 구조물, 벽과 떠 있는 블록, 긴 직선 통로, 구석과 좁은 길, 가시는 바닥 일부만.
4. 라운드마다 맵 교체: `MatchState`에 순환 상태(시드, 섞은 순서, 위치). 6개를 다 쓰기 전에는 반복하지 않고, 순서가 다시 섞일 때도 바로 앞 맵이 이어지지 않는다. F2는 맵 고정(순환 ↔ 맵 하나).
5. 테스트(CP12-1, 2), Smart 봇 측정(CP12-3), 전경 캡처(CP12-4).

## 2. 작업 기록

- 2026-11-01 경기장 크기 리팩터링: `ArenaDef`의 상수 `Columns/Rows/HalfWidth/HalfHeight` → 인스턴스 속성(기존 생성자는 32 × 18). 맵 체크섬에 크기 포함. 파서는 크기를 격자에서 읽고(가로 32~40, 세로 18~22), 다른 검증 뒤에 좌우 대칭('1'↔'2')을 검사한다. v1 맵 3개는 이미 대칭이라 그대로 통과. 테스트 안에서 만드는 비대칭 고정 맵만 `requireSymmetry: false`(첫 시도에서 대칭 검사를 다른 검증보다 먼저 해 기존 오류 메시지 테스트 4개가 깨졌고, 순서를 바꿔 해결). 경계 밖 검사(`TerrainCollision`), 배경 텍스처 범위·광원·먼지, 지형 위쪽 테두리 숨김, 점수 점 위치, 카메라(`FitArena`)를 맵 크기로. EditMode 366/366.
- 맵 순환: `ArenaRotation`(S-109)을 `MatchState`에 넣고 체크섬·상태 비교에 포함. `SimWorld`는 맵 배열을 받고 `Arena`는 지금 라운드의 맵. RoundTransition과 MatchEnd 뒤 새 경기에서 한 칸 진행. `SimState.CreateMatch`. 입력 기록 버전 3(맵 이름 목록 + 순환 상태, 버전 2 읽기 유지).
- 게임 계층: `ArenaMeta`(짝 파일), `MatchRunner.ResolveArenas/RotationNames/ArenaChoices/GetMeta`, F2 선택지(S-110), Main 씬 `Rotation` + 경기마다 시드. 연출은 시뮬레이션의 현재 맵이 그려진 맵과 다르면(라운드 교체) 테마·배경·지형·KO 파편 충돌·카메라·HUD를 다시 그린다. 테마는 짝 파일에서(CP11의 맵 이름 임시 규칙 제거).
- 새 맵 6개(S-111): 왼쪽 절반을 적고 뒤집어 만드는 스크립트로 생성(대칭 보장). 첫 배치의 문제와 조정(S-112):
  - 밀도 10~13%, 가장 큰 빈 정사각형 최대 9 → 구조물을 더해 15.4~15.8%, 5~7.
  - 봇 라운드 평균: Crossing 34.9초, Pillars 41.9초(시작 칸 옆 4~5칸 벽이 경기를 가름) → 벽 아래를 터서 11.1초, 17.8초.
  - Terrace: 가운데 가시 4칸이 데미지의 54% → 가시 제거 후 34.9초 → 시작 칸 벽 제거 시 76.5초(바닥 가까이 떠 있는 블록에 봇이 머리를 부딪힘) → 바닥 블록을 위로 옮겨 15.2초.
- 캡처 메뉴 `Run Scenario Captures (Current CP)`(S-113), 시나리오 `showcase_cp12_<맵>` 6개.
- 테스트 추가: `MapV2Tests`(EditMode 23), `ArenaPlayTests` 도달 가능성 12건, `BotInvariantTests` 새 맵 6건, `MapRotationPlayTests`(PlayMode 1).

## 5. 인계 사항

- 경기 순환은 `MatchRunner.ArenaName == "Rotation"`(Main 씬 기본). 맵을 더하려면 `Data/Arenas/<이름>.txt` + `<이름>.json`("rotation": true)을 두고 `Knockbox/Setup/Ensure Scene Objects`로 씬 목록을 갱신한다. 순환은 최대 8개(`ArenaRotation.MaxArenas`).
- 맵 생성 스크립트는 세션 임시 폴더에만 있었다. 맵을 고칠 때는 격자 파일을 직접 고치고(파서가 대칭을 검사), `MapV2Tests`와 도달 가능성 테스트를 다시 돌린다.
- 짝 파일의 `props`는 CP13에서 채운다(지금은 배열인지만 검사).
- Vault만 가시가 있고 데미지의 27%가 가시다. CP15 손맛 점검에서 지형 데미지 쏠림을 다시 본다.
- CP11은 성능 재측정(외부 부하 없을 때 PlayMode 전체 → cp-11 태그)이 그대로 남아 있다.
