## 1. 계획

1. F-1 천장 순간이동: `FighterPush`의 "위에 선 쪽" 분기가 천장을 확인하고, `ResolveX`는 이번 틱에 가로로 들어간 상자만 막는다. 재현 경기와 단위 테스트, 봇 불변식 점검을 회귀 테스트로.
2. F-2 효과음: 전체 볼륨 여유 + 최종 출력의 부드러운 리미터(AudioListener의 `OnAudioFilterRead`). 봇 영상 녹화도 같은 계산을 써서 게임과 영상의 소리를 맞춘다.
3. 디버그 표시: 빌드에서는 상태 글자와 틱·설정 줄을 기본으로 숨기고 키 하나로 켠다. 에디터는 지금처럼.
4. 모드 정리: 기본 모드 A, 빌드의 F1 순환에서 테스트 공격 모드 제외, 모드 B 동결 표시.
5. 검증: CP10-1~5, 빌드 첫 화면 캡처와 키 입력 후 캡처.
