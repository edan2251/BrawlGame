## 1. 계획

1. 팔레트 v2(08 2절 공통 토큰 + 테마 3종)와 기존 에셋 업그레이드, 모든 연출 색 재배치.
2. 배경: 어두운 바탕, 광원 하나, 지형이 배경에 드리우는 그림자, 미세한 질감, 먼지 입자. URP 2D 광원 대신 직접 계산해 그린다(08 3절이 허용한 대안).
3. 지형 외곽선·윗면 띠·평면 그림자 제거, 화면 위 테두리 띠 제거, 캐릭터 잉크 외곽선 유지.
4. 후처리: 블룸, 색수차 펄스, 비네트(실행 중 만드는 Volume).
5. HUD 최소화(왼쪽 위 점수 점, 머리 위 체력 바), 테마 3종 비교 캡처와 Rounds 캡처 비교, 측정 테스트.

## 2. 작업 기록

- 2026-10-31 팔레트 v2, 지형·배경·후처리·HUD·연출 색 재배치, 시나리오 `theme` 필드와 테마별 비교 시나리오 12개.
- 2026-11-01 팔레트 에셋 업그레이드가 처음엔 건너뛰어짐(필드 초기값 2가 저장 안 된 예전 에셋에도 들어감) → 버전 필드 초기값 제거.
- 화면 위 테두리 띠 제거(한 번은 비교 경계가 1e-3 어긋나 남아 있었음).
- 성능 측정이 한 번 KO 구간 16~21 ms로 나왔으나, 같은 장면을 후처리·색수차·연출 물리 켬/끔으로 나눠 재 보니 모두 약 8 ms였다. Unity 창이 앞에 없어 에디터가 느려진 실행이었다(같은 실행의 틱 테스트가 10초에 791프레임). 창을 앞으로 가져온 뒤 다시 재서 KO 9.5 ms, 일반 9.2 ms.
- 2026-11-01 사용자 요청으로 그림자 기준 변경(D-028): CR-001과 CHECKPOINTS의 CP11-3을 새 기준으로 고치고, 08 3절도 맞춤.
  - 배경을 텍스처 한 장으로 다시 만듦: 광원 y 13.5 → 22.5(화면 위 13.5), 화면 전체를 비추는 거리 감쇠(지수 0.7), 넓은 광원 8표본의 반그림자 + 상자 흐림 2회, 그림자 = 같은 빛 색 × 0.75. 원뿔 메시와 검은 그림자 다각형은 없앰.
  - 측정 테스트 3개(그림자 비율·경계 폭, 빈 경기장 광원 분포). 처음 실행에서 사이언 테마만 아래쪽이 72%(기준 40~60%)로 나옴 → 후처리를 끄면 58%. URP 블룸이 가장 밝은 지형(사이언)까지 번져 어두운 배경을 밝힌 것. 문턱값을 0.92 → 1.0으로 올려도 72%라, URP 블룸 대신 연출별 글로(몸 둘레, 명중·클래시·패링·벽꽝·KO)로 바꿈 → 세 테마 모두 통과.
  - 내 계단 검사(이웃 측정점 차이)는 처음 3%로 잡았다가 배경 질감(±3%)에 걸려 8%로 바꿈(원뿔 경계는 수십 % 계단이라 여전히 잡힘).
- 성능: 그림자 수정 뒤 CP3-5가 17~25 ms로 실패. 같은 장면을 후처리·글로·배경·렌더 텍스처를 하나씩 끄며 재 보니 모두 비슷했고(17~24 ms), 몇 분 뒤 같은 진단은 10.4~11.7 ms, 연출 계층 CPU는 프레임당 0.075 ms, 연출을 끈 에디터 자체가 9.3 ms였다. 컴퓨터에서 RainbowSix(약 2코어 사용)와 원격 데스크톱 호스트가 함께 돌고 있어 측정이 실행마다 크게 흔들린다. 같은 기준이 세 번 넘게 실패해 멈추고 원인을 분석함(코드가 아니라 외부 부하). 아래 검증 표와 7절 참고.

### 08 7절 체크리스트(테마 3종 캡처를 Rounds 캡처와 나란히)

1. 화면 대부분이 어둡고 지형·캐릭터가 떠 보이는가: 예. 배경은 어두운 보라(A·B)·청록(C), 지형과 몸이 밝게 뜬다.
2. 광원에서 뻗는 긴 그림자와 빛줄기: 그림자는 옅고 부드럽게 보인다(D-028). Rounds처럼 빛줄기가 또렷하게 갈라지지는 않는다 — 지금 맵에 구조물이 적어서다(CP12에서 맵이 촘촘해지면 다시 본다).
3. 고정 지형과 움직이는 구조물이 색으로 구분되는가: 구조물은 CP13부터. 팔레트 값으로는 밝기 차가 4~7배(CP11-4).
4. 두 캐릭터가 어디서나 바로 찾아지는가: 예(대비 4:1 이상, 몸 둘레 글로).
5. 명중·클래시·KO가 눈에 띄는가: 예. 흰 섬광·글로·색수차, KO는 화면 번쩍임.
6. 화면 가장자리 띠·액자: 위쪽 띠는 없앴다. 양옆 벽과 바닥은 1유닛 지형으로 남아 있다(CP12에서 경기장을 넓히며 일부를 화면 밖으로).
7. 배경 요소가 지형처럼 보이는 곳: 없다(큰 도형 실루엣 제거).
8. Rounds 에셋을 옮긴 것 같은 요소: 없다(캐릭터는 사각형·잉크 외곽선, UI는 점과 짧은 영문).

## 6. 알려진 문제와 미룬 것

- 양옆 벽과 바닥이 화면 가장자리에 1유닛 띠로 보인다(CP12 카메라·경기장 크기에서 처리).
- 구조물 색은 아직 화면에 없다(CP13).
- 배경 텍스처는 맵·테마가 바뀔 때 CPU로 계산한다(약 2.6만 텍셀 × 8표본). 움직이는 구조물의 그림자(CP13)는 따로 설계해야 한다.
- 지형 붓질 질감(08 4절 "선택")은 넣지 않았다.
