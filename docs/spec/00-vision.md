# 00. 비전과 범위

## 게임 한 문단

두 개의 사각형이 한 화면짜리 작은 경기장에서 부딪히고, 튕기고, 벽에 박힌다. 한 라운드는 10~30초 안에 끝나고, 먼저 정해진 라운드를 가져가는 쪽이 이긴다. 움직임 자체가 공격이고 지형 자체가 무기인 근접 물리 대전이 목표다. 최종적으로는 온라인 1대1 대전과, 라운드에서 진 쪽이 업그레이드를 고르는 성장 시스템을 갖춘다.

## 세 가지 축과 판단 기준

| 축 | 플레이어가 느껴야 하는 것 | 프로토타입에서 확인할 질문 |
|---|---|---|
| 탄력 있고 물리적인 움직임 | 입력에 즉시 반응하고, 튕기고, 관성이 살아 있다 | 아무것도 안 하고 맵을 뛰어다니기만 해도 재미있는가 |
| 지형과 위치를 활용하는 1대1 | 벽, 발판, 구석이 유리함과 불리함을 만든다 | 같은 공격이라도 어디서 하느냐에 따라 결과가 다른가 |
| 강한 타격감과 예쁜 플랫 화면 | 맞는 순간이 묵직하고, 화면은 깔끔하고 읽기 쉽다 | 소리를 끄고 봐도 누가 누구를 때렸는지 바로 보이는가 |

## 이 프로토타입의 목표

1. 이동과 지형 충돌의 **손맛 기준선**을 만든다.
2. 전투 후보를 **한 빌드 안에서 전환하며 비교**할 수 있게 한다.
   - 주 모드 A: **돌진 충돌** (몸이 곧 무기, 더 빠른 쪽이 이긴다)
   - 주 모드 B: **무기 휘두르기** (방향별 근접 공격)
   - 보조 스킬: **잡기·던지기** (두 모드 모두에서 사용)
3. 첫 빌드부터 **보기 좋은 화면**을 갖춘다. 플랫한 도형, 절차적 팔다리(IK), 타격 연출.
4. 온라인 롤백을 얹을 수 있는 **결정론적 시뮬레이션 구조**를 처음부터 지킨다.
5. 마지막에 사용자가 직접 플레이해 보고 전투 방향을 고를 수 있는 **비교용 빌드**를 낸다.

## 범위에 넣지 않는 것

- 업그레이드 카드 시스템. 전투 방식이 확정된 뒤 별도 명세로 다룬다. 단, 라운드 사이에 "선택 화면"이 끼어들 수 있는 훅만 만들어 둔다.
- 온라인 대전 구현. CP10은 초안만 있고 착수 전에 질문이 필요하다.
- AI 상대. 대신 테스트용 허수아비(정해진 행동 반복)를 만든다.
- 메뉴, 설정 화면, 저장, 현지화, 사운드 믹싱 같은 출시용 기능.
- 경사면, 움직이는 발판, 부서지는 지형(게임 결과에 영향을 주는 것). 연출용 파편은 허용.

## 고유한 정체성

스타일의 방향(플랫한 도형, 선명한 대비색, 단순한 배경)은 ROUNDS와 Square Brawl을 참고하되, 캐릭터·UI·카드·로고는 따라 하지 않는다. 고유한 팔레트와 캐릭터 얼굴, 장난감 같은 "잉크 외곽선" 표현으로 구분되는 인상을 만든다. 자세한 내용은 `05-presentation.md`.

## 성공의 모습

사용자가 비교용 빌드를 친구와 10분 동안 플레이한 뒤 "이 방식으로 가자"고 말할 수 있으면 성공이다. 수치가 덜 다듬어진 것은 괜찮지만, **세 축 중 하나라도 확인할 수 없는 상태**면 실패다.
