# 08. 화면 방향: Rounds 추종

> `05-presentation.md`의 1절(아트 디렉션), 4절의 연출 색, 6절(HUD)을 이 문서가 대체한다. 팔다리 IK, 몸 변형, 타격 연출의 구조와 타이밍, 연출 전용 물리, 소리는 05를 그대로 따른다.

## 1. 원칙

- **어두운 배경 위의 밝은 것.** 화면 대부분은 거의 검은 남색이고, 지형과 캐릭터와 연출이 그 위에서 빛난다. 캐릭터가 작아도 읽히는 이유가 이 명암 구조다.
- **빛은 위에서 하나.** 화면 위 가운데 바깥의 광원이 배경을 비추고, 모든 지형과 구조물이 배경에 길고 각진 그림자를 드리운다. 구조물 사이 틈으로 빛줄기가 생긴다.
- **물체는 플랫하게.** 지형, 구조물, 캐릭터는 조명의 영향을 받지 않는 단색(미세한 질감 허용)이다. 빛과 그림자는 배경에만 생긴다.
- **고정은 밝게, 움직이는 것은 탁하게.** 고정 지형은 테마의 밝은 주색, 움직이는 구조물은 같은 계열의 어둡고 탁한 색이다. 밟아도 안전한 곳과 움직이는 곳이 색으로 구분된다.
- **에셋은 따라 하지 않는다.** Rounds의 구성, 분위기, 표현 방식은 따라가되 캐릭터 디자인, 카드 그림, UI, 로고는 만들지 않는다. 캐릭터는 사각형 몸과 잉크 외곽선을 유지한다.

참고 자료: 로컬의 `References/rounds/`(Rounds 캡처, 커밋 금지), 저장소의 `docs/references/palette-preview.png`(이 문서의 색으로 만든 견본 장면).

## 2. 색 토큰

사용자의 다른 게임(CursorDash) 핵심 팔레트에서 뽑았다. 모든 색은 `PaletteAsset`에 두고 코드에 직접 쓰지 않는다. 값은 6절의 검사 기준을 지키는 범위에서 자체 결정으로 조정할 수 있다.

### 공통

| 토큰 | 값 | 용도 |
|---|---|---|
| `bgBase` | `#030512` | 배경 바탕, 그림자 영역. Rounds 캡처의 그림자 부분(`#00071A`)과 거의 같다 |
| `ink` | `#020304` | 캐릭터 외곽선, 팔다리, 눈 |
| `p1Body` / `p1Shade` | `#FFD466` / `#D1AE54` | P1 골드 |
| `p2Body` / `p2Shade` | `#CB49FF` / `#AD1FFF` | P2 퍼플 |
| `flash` | `#FFFFFF` | 섬광, 글자 |
| `hit` | `#FF0A14` | 피격 파편, 체력 감소분, 가시, 돌진 위험 외곽선. **다른 용도로 쓰지 않는다** |
| `energy` | `#14F0DB` | 메인 색. 충전 단계, 패링 고리, 클래시 빛, 승리 표시 |
| `energySoft` | `#3DE0CF` | 충전 1단계, UI 강조 |
| `mote` | `#5CC2D6` | 빛줄기 속 먼지 입자(낮은 불투명도) |
| `uiSub` | `#8C949E` | 보조 글자 |
| `uiEmpty` | `#667885` | 빈 점수 점, 체력 바 바탕 |

### 맵 테마

| 테마 | 빛 색(`light`) | 고정 지형(`static`) | 구조물(`prop`) |

| A 민트 | `#330947` 바이올렛 | `#11C1B3` | `#225857` |

- 지형 색에 플레이어 색(골드, 퍼플)이나 `hit` 빨강을 쓰지 않는다.
- 줄(구조물을 매단 선)은 `prop` 색의 가는 선.

## 3. 조명과 그림자 (URP 2D)

- 전역 광원(Global Light 2D)은 아주 어둡게 두어, 빛이 닿지 않는 배경이 `bgBase`로 남게 한다.
- 주 광원 하나: 화면 위 가운데 바깥(경기장 위쪽 끝에서 대략 화면 높이의 1/4 위)에 두는 Point Light 2D. 맵 데이터가 위치를 바꿀 수 있다. 빛 색은 테마의 `light`, 반경은 경기장 전체를 덮게.
- **배경만 빛을 받는다**(Lit 재질). 지형, 구조물, 캐릭터, 연출은 Unlit 재질로 플랫하게 그린다.
- 지형 상자와 구조물에 Shadow Caster 2D를 붙여 배경에 그림자를 드리운다. 구조물이 움직이면 그림자도 매 프레임 따라 움직인다. 캐릭터의 그림자는 성능과 보기에 따라 자체 결정.
- 그림자는 경계가 또렷한 편이 Rounds에 가깝다. 부드러움은 약하게.
- 이 구성이 Unity 6000.3의 2D 렌더러에서 성능이나 표현상 맞지 않으면, 같은 모습을 내는 다른 방법(그림자 다각형을 직접 계산해 그리기 등)으로 바꿔도 된다. 바꿨다면 자체 결정으로 기록한다.

## 4. 배경과 질감

- 배경은 `bgBase` 단색 + 코드로 만든 미세한 질감(붓질이나 얼룩 같은 저주파 노이즈, 밝기 ±3% 이내). 외부 이미지를 쓰지 않는다.
- 이전의 큰 사각형·원 실루엣은 제거한다. 배경 도형이 지형처럼 보이면 안 된다.
- 빛줄기 안에 `mote` 입자가 천천히 떠다닌다(연출 전용, 개수 적게).
- 지형에 아주 약한 질감(테마 색의 명도 차 ±5% 이내 붓질)을 넣는 것은 선택. 넣는다면 코드로 생성.
- **화면을 감싸던 남색 띠를 없앤다.** 화면 끝까지 게임 화면이며, 경기장 테두리 벽은 테마 지형 색으로 일부가 화면 밖으로 나가도 된다.

## 5. 후처리와 연출 색

- **블룸**: 문턱값을 높게 두어 흰 섬광, 민트 에너지, 캐릭터 몸의 밝은 부분 정도만 살짝 번지게. 지형 전체가 번지면 안 된다.
- **색수차**: 평소 0. KO 순간 강하게(예: 0.6에서 0.25초 동안 0으로), 데미지 15 이상 명중과 벽꽝에 약하게. 흔들림 줄이기(F7)를 켜면 끈다.
- **비네트**: 약하게(0.2 안팎).
- 연출 색 배치:

| 연출 | 색 |
|---|---|
| 명중 섬광, 고리 | `flash` |
| 명중 파편 | `hit` 위주에 공격자 몸 색 일부 |
| 클래시 | `flash` 중심 + `energy` 빛 |
| 패링 고리 | `energy` |
| 충전 1·2·3단계 외곽선 | `energySoft` → `energy` → `flash` 깜박임 |
| 돌진 위험 외곽선 | `hit` |
| 잔상 | 플레이어 몸 색, 낮은 불투명도 |
| 먼지 | `uiSub` 낮은 불투명도 |
| 벽꽝 금 자국 | 지형 위에 `bgBase` 선 |

## 6. HUD

- 점수: 화면 왼쪽 위에 작은 점 두 줄(P1 골드 줄, P2 퍼플 줄, 빈 점은 `uiEmpty`).
- 체력 바: 머리 위에 작게. 깎인 부분은 `hit`로 잠깐 남았다가 줄어든다.
- 가운데 문구(READY, GO, KO, P1 WINS): `flash` 색, 짧고 크게.
- 디버그 글자(상태, 틱, 설정 줄)는 빌드에서 기본으로 숨긴다.

## 7. 시각 검증 체크리스트

캡처를 `References/rounds/`의 같은 종류 장면과 나란히 놓고 답한다.

1. 화면 대부분이 어둡고, 지형과 캐릭터가 그 위에서 떠 보이는가
2. 광원에서 뻗는 긴 그림자와 틈 사이 빛줄기가 보이는가
3. 고정 지형과 움직이는 구조물이 색만으로 구분되는가
4. 두 캐릭터가 어느 테마, 어느 위치(빛 영역, 그림자 영역, 밝은 지형 앞)에서도 바로 찾아지는가
5. 명중, 클래시, KO 순간이 캐릭터가 작아도 화면에서 눈에 띄는가
6. 화면 가장자리에 띠나 액자가 없는가
7. 배경 요소가 밟을 수 있는 지형처럼 보이는 곳이 없는가
8. Rounds의 특정 에셋을 그대로 옮긴 것처럼 보이는 요소가 없는가
