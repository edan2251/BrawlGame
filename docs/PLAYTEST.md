# KNOCKBOX 플레이테스트 안내 (M2, CP24)

가위·바위·보 폼 전투와 성장 루프(세트 패자 선택, 경기 끝까지 누적)를 처음 끝까지 해 볼 수 있는 빌드입니다. 수치는 모두 시험용입니다(D-045). 이전 비교 빌드 안내(CP9)는 `docs/archive/PLAYTEST.md`.

## 1. 실행

- 빌드: `Builds/Windows/Knockbox.exe`(개발 빌드, Git 제외). CP16 기준 빌드는 `Builds/Baseline_CP16/`.
- 처음 실행하면 도움말(`~`)이 열려 있습니다. 첫 실행 때 Windows 방화벽 창이 뜰 수 있습니다(개발 빌드).
- 2인: P1은 키보드 왼쪽, P2는 연결된 첫 게임패드, 없으면 키보드 오른쪽(넘패드 필요). F6으로 P2를 봇으로 바꿀 수 있습니다.
- 자동 진행(확인용): `Knockbox.exe -autobots -ticksperframe 20` 이면 봇 대 봇이 빠르게 경기를 반복하고 흐름이 `Player.log`에 `[Knockbox][flow]`로 남습니다.

## 2. 경기 구조

| 단위 | 규칙 |
|---|---|
| 경기 시작 | 둘 다 **초기 폼을 비공개로 동시에** 고릅니다(경기당 한 번) |
| 라운드 | 한 번 싸워 KO로 승패. 동시 KO는 무승부(점수 없이 다시) |
| 세트 | **3라운드 중 2선승** |
| 세트가 끝나면 | **세트에서 진 쪽만** 하나를 고릅니다: 새 폼 획득 또는 증강(최대 4개 중) |
| 경기 | **5세트 선승**. 한 선수의 선택은 경기당 최대 4번 |
| 누적 | 폼과 증강은 **경기 끝까지 유지·누적**. 세트가 끝나면 라운드 점수만 0으로 |
| 재시작 | 경기 종료 화면에서 아무 버튼 → 폼·증강·선택 수·세트스코어 초기화, 초기 폼부터 다시 |

## 3. 조작

| 동작 | P1(키보드 왼쪽) | P2(키보드 오른쪽) | 패드 |
|---|---|---|---|
| 이동·조준 | WASD | 방향키 | 스틱·방향 패드 |
| 점프 | Space | Num0 | A |
| 공격(폼의 기본공격) | F | Num1 | X |
| 이동 대시 | Left Shift | Num2 | B, RT |
| **폼 전환**(보유한 다음 폼) | **R** | **Num5** | **RB** |
| 가드·잡기(기본 꺼짐) | E · Q | Num3 · Num4 | LB/LT · Y |

**선택 화면**: 자기 쪽 화면 절반에 `[키] 이름`으로 나옵니다. 1~4번 = **점프 / 공격 / 대시 / 가드** 키(P1: Space/F/Shift/E, P2: Num0/1/2/3). 고르면 READY만 보이고 무엇을 골랐는지는 표시하지 않습니다. 15초 안에 고르지 않으면 무작위로 정해집니다.

### 폼

| 폼 | 공격 버튼 | 에너지 비용 | 상성(속성 비교) |
|---|---|---|---|
| 가위(삼각형) | 누르고 있으면 충전, 떼면 돌진(8방향) | 50, 발사할 때 | 위력 6 이상 돌진은 보의 공격을 끊고 이긴다 |
| 바위(원) | 선딜 뒤 투사체 발사(8방향) | 45, 발사할 때 | 투사체가 돌진 중인 상대를 맞히면 돌진이 끊기고 짧게 기절 |
| 보(사각형) | 앞 휘두르기 | 40, 시작할 때 | 휘두르는 판정이 투사체를 되받아친다(반사) |

- 에너지(체력 바 아래 민트 줄): 최대 180, 공격이 끝나고 1초 뒤 회복 시작, 바닥나면 공격이 시작되지 않지만 이동·점프·대시는 됩니다. 다음 공격 비용보다 적으면 줄이 회색.
- 같은 종류끼리: 가위끼리·보끼리는 클래시, 투사체끼리는 서로 사라집니다.

### 증강(대표 4개, 이름은 임시)

| 이름 | 폼 | 효과 |
|---|---|---|
| SPEED | 가위 | 돌진 속도 ×1.2, **최대 3번** 쌓임(×1.73) |
| INSTANT | 가위 | 충전 없이 누른 순간 돌진(속도 26 × SPEED 배율) |
| PIERCE | 바위 | 투사체가 보에게 반사되지 않음(보를 그대로 맞힘) |
| REFUND | 보 | 휘두르기가 맞으면 에너지 20 환급 |

증강이 발동하는 순간 머리 위에 이름이 잠깐 뜹니다(평소에는 표시 없음).

## 5. 사용자 확인 포인트

플레이하면서 아래를 봐 주세요. 자동 테스트와 봇으로 판단할 수 없어 사람 확인이 필요한 항목입니다.

1. **폼 전환의 느낌**: 전환 버튼(R)이 자연스러운가, 상대를 보고 바꾸게 되는가. 봇 기준 전환 지표: 1분에 45~111번(봇은 과하게 바꿈).
2. **세트 패자 선택의 경제**: 새 폼과 증강 중 무엇을 고르게 되는가, 가위에만 몰아주는 전문화(SPEED ×3 + INSTANT)가 재미있는가.
3. **비공개 심리전**: 상대가 무엇을 골랐는지 모르는 긴장이 있는가(한 화면이라 완전한 비공개는 아님, 아래 알려진 문제).
4. **현재 폼 표시 세 방식(HOME)**: 늘 표시 / 행동 때만 / 작은 표시 중 무엇이 좋은가.
5. **가드·잡기를 끈 느낌**(F4로 켜서 비교).
6. **에너지 느낌**(Insert로 꺼서 비교): 라운드가 길어지는지, 막히는 느낌인지.
7. **불리한 폼으로도 대응 방법을 찾을 수 있는가.**
8. **경기 길이**: 봇 기준 5세트 선승 경기 7~16분.
9. 손맛·화면 구성·연출(투사체, 반사, 기절, 바위 선딜, 선택 화면, 증강 표시).

## 6. 알려진 문제

- **한 화면 2인에서는 선택을 완전히 비공개로 할 수 없습니다**(D-046). 선택지는 고르는 쪽 절반에만 보이고 결과는 표시하지 않는 방식으로 근사했습니다.
- 선택 화면의 키 이름은 키보드 기준입니다(패드는 A/X/B/LB 순서가 1~4번).
- 에너지를 켜면 라운드가 길어지고(봇 평균 약 43초, 끄면 25초), 봇 기준으로 의도한 상성 방향이 뒤집히는 경향이 있습니다(`docs/progress/M1-summary.md`).
- 봇은 상성을 노리지만 서툴고, 폼 전환을 지나치게 자주 합니다.
- 서로 다른 소유자의 투사체 두 개가 같은 틱에 한 파이터를 맞히는 드문 경우는 처리 순서가 고정입니다(거울상 비대칭).
- 수치(비용, 속도, 기절 시간, 증강 효과)는 모두 시험값입니다.
