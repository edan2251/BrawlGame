# 결정 기록

세 종류를 구분한다.

- **D (확정/기본값)**: 사용자가 정한 것, 또는 기획 대화에서 제안해 기본값으로 둔 것. 기본값을 바꾸는 것은 기획 결정이므로 사용자에게 묻는다.
- **S (자체 결정)**: Claude Code가 명세 범위 안에서 스스로 정한 것. 묻지 않고 기록만 한다.
- **Q (대기 질문)**: 사용자 답이 필요한 것. 답을 받으면 D로 옮기고 Q에는 "→ D-번호"라고 남긴다.
