## 1. 계획

- `AugmentDef`(대상 `Target`, 희귀도 `Rarity`, `Priority`, `MaxStacks`, 수정자 ①가산 ②배율 ③플래그 ④슬롯·트리거, `Targets`/`Removes`). 설정의 증강 목록(기본 4개, 테스트는 전용 증강을 더함).
- 효과는 획득 목록(`AugmentState` 4칸)에서 매번 계산: 휴면 → ① → ② → ③(우선순위) → ④(슬롯 우선순위). 트리거는 Priority → Id, 연쇄 깊이 1.
- 후보 필터(대상 폼 보유, 중복 상한, 슬롯 점유, 무의미 조합), 선택 단계 연결, 대표 증강 4개(속도 배율 3중복, 즉발, 철갑탄, 환급), 발동 표시.

- 2026-11-02 구현, 컴파일 오류·경고 0.
