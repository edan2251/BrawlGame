## 7. 인계 사항

- 코드: CP16과 같음(테스트 카테고리·시간 기록기·측정 방식만 바뀜). 다음은 CP18(파이터별 폼 기반, 에너지, 스위치).
- 개발 중 테스트: `run_tests` EditMode `category_names: ["!Slow"]`(약 2.5분). CP 끝에만 전체(포커스 상태 약 20분, 도달성 탐색이 대부분).
- `refresh_unity`는 `mode: force, scope: all`로 불러야 새 스크립트를 확실히 컴파일한다(`if_dirty`는 새 파일을 놓친 적 있음). 컴파일 확인은 `Library/ScriptAssemblies/*.dll` 시각으로.
- 실시간 PlayMode 측정은 Unity가 포그라운드여야 한다. 사용자가 다른 프로그램(게임)을 쓰는 중이면 포커스를 빼앗지 않는다.
- CP18 설계 메모: 폼 = 파이터 상태(가위·바위·보 + 기존 테스트용 Test), `SimConfig`의 CombatMode는 시작 폼으로만 쓰고 시뮬레이션 분기는 파이터 폼으로. 기존 생성자 = 레거시 스위치(가드·잡기 켬, 에너지 끔), 새 기본 = 가드·잡기 끔, 에너지 켬. 튜닝 에셋은 새 필드가 YAML에 없으면 `CombatParams.Default` 값을 쓴다.
