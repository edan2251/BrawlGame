## 1. 계획

- 보: 모드 B 코드를 앞 휘두르기 하나로(`Swing.ForwardOnly`). 레거시 생성자는 방향 휘두르기 유지.
- 속성 해석기: 반사(보 활성 판정 × 반사 가능 투사체), 투사체 → 돌진 기절, 돌진(위력 ≥ 6) → 근접 중단, 투사체끼리 상쇄. 판정은 속성(돌진 위력, 활성 판정, `Reflectable`)으로, 폼 쌍 분기 없음.
- 파이터마다 시작 폼(`RuleSet.WithForms`), 바위 봇, 봇 매트릭스, 성능 기록, `M1-summary.md`.

## 2. 작업 기록

- 2026-11-02 구현, 컴파일 오류·경고 0. 새 테스트 28개.
- 레거시 모드 B 시험 6개가 앞 휘두르기만 쓰게 되어 깨짐 → 레거시 생성자(가드 켬·에너지 끔과 같은 "CP16 규칙")가 `ForwardOnly = false`를 쓰게 함(S-152). 테스트 수정 없음.
- 새 테스트 4개 실패: 주입 투사체가 판정 원 높이(몸 위 1.0)라 몸을 비켜 감 → 몸 높이로(테스트 수정). 돌진이 보를 이긴 뒤 같은 돌진으로 한 번 더 맞힘 → 한 돌진은 이긴 상대를 다시 치지 않게 접촉 대기를 돌진 최대 시간으로(S-152).
- 봇 매트릭스 1차: 위반 25(바위 대 바위 24경기가 2분 동안 라운드가 끝나지 않음 = 투사체끼리 계속 상쇄, 그 밖 1). 튜닝 1회(바위 봇 발사 간격 무작위, 셋 중 하나 점프하며 쏨, 멀면 다가감, S-153) 뒤 위반 0, 끝나지 않은 경기 1(조합 단위로는 0).
- 설정 체크섬 범위 테스트가 레거시 생성자로 `ForwardOnly` 변화를 못 봄 → 규칙 생성자로 확인(테스트 수정).
- 상자 40개 롤백 2.06 ms(부하) → 한 번 재측정 통과(D-048).
- 새 구조(경기 구조 검토)와 충돌하는 구현: 없음. `RuleSet`의 시작 폼은 라운드마다 다시 적용된다(라운드·세트 유지 규칙은 CP22 범위).
